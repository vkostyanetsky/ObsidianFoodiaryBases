# Календарь периодических задач для Obsidian 📆 🔁 ✅

В этом примере периодические задачи хранятся как обычные Markdown-заметки, а
[Obsidian Bases](https://help.obsidian.md/bases) показывает записи для сегодня,
вчера или выбранной ежедневной заметки. Используются только встроенные плагины
Obsidian.

Календарь подсказывает, какие наборы задач актуальны, после чего нужный чек-лист
копируется в ежедневную заметку. Благодаря этому состояние выполнения относится
к конкретному дню, а исходная периодическая заметка остаётся неизменным
шаблоном.

## 🚀 Как запустить пример

1. Откройте папку [vault](vault) как хранилище Obsidian.
2. Если Obsidian запросит разрешение, включите встроенные плагины **Базы**,
   **Ежедневные заметки** и **Шаблоны**.
3. Откройте [Calendar.base](vault/Calendar/Calendar.base): в нём есть виды
   **Today** («Сегодня») и **Yesterday** («Вчера»).
4. Выполните команду создания ежедневной заметки. Она появится в папке
   `Daily Notes` с именем `YYYY-MM-DD` и встроенным видом **Day** («День»).
5. Откройте актуальную запись календаря и скопируйте чек-лист из блока кода в
   раздел **Задачи** ежедневной заметки.

Готовая заметка `2026-08-15` демонстрирует вид **Day** независимо от текущей
даты: на неё приходятся ежедневный, субботний, ежемесячный и ежегодный примеры.

## 👀 Как всё устроено

Каждая заметка внутри `vault/Calendar` описывает периодический набор задач. База
выбирает заметки, у которых включены свойства `calendar_active` и
`calendar_visible`, а затем проверяет одно из расписаний:

- `calendar_days_of_week_days` — дни недели по ISO от `1` (понедельник) до `7`
  (воскресенье);
- `calendar_day_of_month_day` — день месяца. Без свойства
  `calendar_day_of_month_month` задача повторяется каждый месяц, а при указании
  месяца от `1` до `12` — раз в год.

Если в заметке заданы оба расписания, она появляется при совпадении любого из
них. Необязательное свойство `calendar_icon` выводится в первом столбце.

В базе настроены три вида:

- **Today** — записи на сегодня;
- **Yesterday** — вчерашние записи, чтобы было удобно проверить пропущенное;
- **Day** — записи на дату из имени текущего файла. Этот вид встраивается в
  ежедневные заметки с именем строго в формате `YYYY-MM-DD`:

```md
![[Calendar.base#Day]]
```

Чек-листы в периодических заметках намеренно заключены в блоки кода. Они
остаются неизменными шаблонами и не попадают в глобальный поиск как постоянно
незавершённые задачи.

## 🛠️ Как добавить периодическую задачу

В папке `Templates` есть готовые шаблоны еженедельной, ежемесячной и ежегодной
задачи. Например, расписание по рабочим дням выглядит так:

```yaml
---
calendar_active: true
calendar_visible: true
calendar_icon: 💼
calendar_days_of_week_days:
  - "1"
  - "2"
  - "3"
  - "4"
  - "5"
---
```

Для ежемесячной задачи первого числа достаточно свойства:

```yaml
calendar_day_of_month_day: 1
```

Для ежегодной задачи 15 августа нужны два свойства:

```yaml
calendar_day_of_month_month: 8
calendar_day_of_month_day: 15
```

Новую заметку можно хранить в любой подпапке `Calendar`: подпапки нужны только
для удобной группировки.

## 📦 Как перенести календарь в своё хранилище

1. Скопируйте в него `vault/Calendar` и нужные файлы из `vault/Templates`.
2. Перенесите раздел календаря из
   [Daily Note.md](vault/Templates/Daily%20Note.md) в свой шаблон ежедневной
   заметки.
3. Убедитесь, что имена ежедневных заметок имеют формат `YYYY-MM-DD`.
4. Если периодические заметки лежат не в корневой папке `Calendar`, измените
   условие `file.inFolder("Calendar")` в `Calendar.base`.
5. При необходимости скопируйте настройки из `.obsidian`, предварительно
   сравнив их со своими, чтобы ничего не перезаписать.

## ⚠️ Ограничения

- Пример поддерживает дни недели, даты месяца и ежегодные даты, но не интервалы
  вроде «раз в две недели» и не правила вроде «последний рабочий день месяца».
- Задачи копируются в ежедневную заметку вручную; их выполнение не
  синхронизируется обратно с периодическими заметками.
- Задача на 31-е число не появится в коротком месяце.
