# Obsidian Fastimer (Bases) ⏳ 🍽️ 🪵

[README in English](README.md)

Это пример хранилища [Obsidian](https://obsidian.md) для учёта интервального
голодания: для каждого фаста видно, когда он начался, сколько планировалось
голодать, когда фаст должен закончиться и сколько он длился на самом деле. Пока
фаст не закончен, его длительность считается от начала до текущего момента.

Для автоматизации используется плагин Templater, а остальное сделано на чистом
Obsidian Bases.

---

## 🚀 Как начать?

### 1. Установите Templater

Включите поддержку плагинов в хранилище и установите
[Templater](https://github.com/SilentVoid13/Templater).

### 2. Настройте Templater

> [!tip]
> Пример уже содержит [файл настроек](vault/.obsidian/plugins/templater-obsidian/data.json)
> Templater, поэтому плагин, скорее всего, заработает без дополнительной
> настройки.

Установите следующие настройки:

- `Template folder location` — выберите папку `Templates`;
- `Trigger Templater on new file creation` — включите;
- `Folder templates` — настройте для одной папки:
    - `Records`: `Templates/Record.md`

### 3. Записывайте фасты

Каждый фаст — отдельная заметка в папке [Records](vault/Records). Их удобно
создавать по кнопке `New` прямо из интерфейса [базы](vault/Fasting.base).

Свойства заметки о фасте (их создаёт Templater при создании нового файла):

- `length` — планируемая длительность фаста в часах (заполняется значением
  `12`; дробные значения вроде `13.5` тоже работают);
- `start` — время начала фаста (заполняется автоматически текущими датой и
  временем);
- `end` — время окончания фаста; пока фаст идёт, свойство остаётся пустым;
- `timestamp` — время / штамп (используется для сортировки и в качестве имени
  файла, заполняется автоматически).

То есть порядок такой: создали заметку, когда перестали есть, и заполнили `end`,
когда фаст закончили. Всё остальное посчитает база.

> [!tip]
> `start` и `end` — обычные свойства с датой и временем, так что их можно
> поправить прямо в панели свойств, если вспомнили о записи чуть позже, чем
> нужно было.

## 👀 Как смотреть?

В [Fasting.base](vault/Fasting.base) настроено два вида:

- **All** — все фасты за всё время, начиная с самых свежих;
- **Day** — фасты, которые попадают на конкретный день.

В обоих видах одинаковый набор колонок:

- **Start** — начало фаста;
- **Planned** — планируемая длительность в формате `ЧЧ:мм`;
- **End (planned)** — `start` плюс планируемая длительность, то есть время, в
  которое фаст должен закончиться;
- **Actual** — фактическая длительность в формате `ЧЧ:мм`; для незакрытого
  фаста (пустой `end`) считается до текущего момента, так что вид работает ещё
  и как таймер;
- **End (actual)** — время, когда фаст закончился на самом деле.

Вид **Day** берёт дату из имени файла, в который встроен, поэтому он
предназначен для встраивания в ежедневные заметки с именами вида `YYYY-MM-DD`:

```md
![[Fasting.base#Day]]
```

Фаст почти всегда переходит через полночь, поэтому этот вид показывает все
фасты, которые задевают день: и начатый вечером предыдущего дня, и начатый
вечером самого дня. Незакрытый фаст показывается всегда.

## 🛠️ Как изменить?

### Другая длительность по умолчанию

Значение `12` часов по умолчанию находится в
[шаблоне записи](vault/Templates/Record.md):

```js
output += `length: 12\n`;
```

Поставьте туда своё привычное число — это всего лишь стартовое значение,
в конкретной заметке его всегда можно поменять.

### Учёт отклонения от плана

Предположим, вы хотите видеть, насколько фактическая длительность отличается
от плановой.

Добавьте в базу формулу:

```js
((if(end, end, now()) - start).hours - length).round(1)
```

После этого добавьте колонку с этой формулой в виды. Положительное число значит,
что вы голодали дольше плана, отрицательное — что закончили фаст раньше.

### Комментарий к фасту

Тело заметки свободно, поэтому проще всего написать комментарий прямо в ней.
Если же комментарии хочется видеть в таблице, добавьте свойство в
[шаблон записи](vault/Templates/Record.md):

```js
output += `note: \n`;
```

А затем добавьте `note` в список `order` нужных видов в
[Fasting.base](vault/Fasting.base) — и колонка появится.
